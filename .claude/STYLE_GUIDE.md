# PUSAKA Brand Style Guide (Keraton Modern)

This theme blends Indonesian heritage with high-end digital security.

## 1. Color Palette (HEX)
| Element | Color Name | HEX Code | Purpose |
| :--- | :--- | :--- | :--- |
| **Primary** | Heritage Indigo | `#2C1E1A` | Main Brand Color / Headers |
| **Secondary** | Keraton Gold | `#D4AF37` | Buttons / Premium Features |
| **Background** | Soft Parchment | `#F9F7F2` | App Background (Main) |
| **Action** | Nusantara Teal | `#006064` | Confirmation / Success States |
| **Alert** | Terracotta | `#BC6C25` | Warning / Security Alerts |
| **Text** | Deep Slate | `#1E293B` | High Readability Body Text |

## 2. Typography
* **Headlines:** *Playfair Display* (Serif) - Gives a sense of history and "Waris" (Legacy).
* **Body/UI:** *Inter* or *Montserrat* (Sans Serif) - Clean, modern, and easy for parents to read.

## 3. UI Accents (Kearifan Lokal)
* **Background Texture:** Use a 3% opacity *Parang* Batik pattern overlay on the **PUSAKA Brankas** dashboard to symbolize "Continuous Protection."
* **Corner Radius:** `12px` (Softened corners) to maintain the "Friendly and Near Us" feel.
* **Iconography:** Use "Linear" style icons with a stroke weight of `1.5pt` in **Keraton Gold**.

## 4. Feature Branding
* **PUSAKA Brankas:** "Simpan dengan Aman" (Store with Safety).
* **PUSAKA Waris:** "Jaga Masa Depan" (Guard the Future).
